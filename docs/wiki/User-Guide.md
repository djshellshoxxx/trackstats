# User Guide

1. Choose a music folder or a set of audio files.
2. TrackStats scans them in the browser. Nothing is uploaded.
3. Review the summary: track count, storage, playback time, formats, bitrate, sample rate, lossless and lossy mix, BPM and key metadata, and common metadata gaps.
4. Use the Track Explorer to search and filter the scan, then export CSV or JSON.

Supported formats in V1: MP3, WAV, FLAC, AIFF, OGG/Opus, AAC/M4A and related audio files. WAV, FLAC and ID3 headers are parsed directly where practical. Browser media metadata is the fallback for duration.
